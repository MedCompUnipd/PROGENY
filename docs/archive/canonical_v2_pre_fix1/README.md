# Historical canonical V2 design contracts (pre-FIX1)

These 14 documents are rebranded copies of historical pre-FIX1 design
contracts, not byte-identical reproductions of the archived originals.
The SHA256 checksums in `SHA256SUMS.txt` attest to the rebranded copies
distributed here; they do not certify the pre-migration bytes.

They are historical design and interface records, **not current executable
scientific contracts**. Where these documents conflict with FIX1 code,
FIX1 tests, or `docs/PROGENY_CANONICAL_V2_SOURCE_BASELINE_STATUS.md`, the
validated FIX1 contract takes precedence.
